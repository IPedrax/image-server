# Assinatura de e-mail · Prefeitura de São Bento do Sul

Imagens usadas na assinatura de e-mail (Zimbra), servidas pelo CDN do jsDelivr.

| Arquivo | Uso | Link no CDN |
|---|---|---|
| `bandeira-sao-bento-do-sul.png` | Bandeira, 300x210 (exibida em 100x70) | https://cdn.jsdelivr.net/gh/IPedrax/image-server@v1.0.0/bandeira-sao-bento-do-sul.png |
| `icone-telefone.png` | Ícone de telefone, 42x42 (exibido em 14x14) | https://cdn.jsdelivr.net/gh/IPedrax/image-server@v1.0.0/icone-telefone.png |
| `icone-telefone.svg` | Original vetorial do ícone | https://cdn.jsdelivr.net/gh/IPedrax/image-server@v1.0.0/icone-telefone.svg |

Os links apontam para a versão `v1.0.0`, que não muda. Para trocar uma imagem, publique uma
nova tag (por exemplo `v1.1.0`) e atualize os links na assinatura.

O ícone vai em PNG na assinatura porque Gmail e Outlook não exibem SVG em e-mails; o PNG foi
gerado a partir do SVG em 3x, para ficar nítido em qualquer tela.

## Créditos

- Bandeira: símbolo oficial do Município de São Bento do Sul (Lei Municipal nº 174/1969),
  recortada do logotipo oficial da Prefeitura.
- Ícone de telefone: "call" do [Material Symbols](https://github.com/google/material-design-icons)
  (Google), licença [Apache 2.0](https://www.apache.org/licenses/LICENSE-2.0), na cor #008248.
